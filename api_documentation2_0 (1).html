Waybill Generation

This REST API is used to get AWB (waybill) number from the shipping provider/aggregator in reference to the shipment (shippingPackage).In this POST request sends the shipment details, pickup and delivery address details. While the shipping provider/aggregator responds with waybill number and a link to download shippingLabel in PDF format.
